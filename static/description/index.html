🔐 ZKteco Biometric Attendance Integration

Advanced integration for Odoo 15.0 with ZKteco biometric devices

Version 15.0.1.0 LGPL-3 Open Source Production Ready

📖 Overview

This powerful Odoo module provides seamless integration with ZKteco biometric devices, enabling automatic employee attendance tracking through fingerprint, face recognition, or card-based authentication. Built with enterprise-grade reliability and performance.

💡 Why Choose This Module?
Eliminate manual attendance tracking, reduce errors, prevent buddy punching, and gain real-time insights into your workforce attendance patterns.

⚙️ How It Works

Upload Employees to Device

  1. Configure your biometric device with IP address and connection details
  2. Click "Upload to Device" button from the device form
  3. System checks device capacity and validates employee data
  4. Employees are uploaded with automatic duplicate detection by name
  5. Card numbers are synchronized automatically

Import Users from Device

  1. Open the biometric device configuration
  2. Click "Import from Device" button
  3. System reads all users from the device
  4. Creates new employees or links to existing ones by name
  5. Imports card numbers and biometric IDs

Download Attendance Logs

  1. Access the device record in Odoo
  2. Click "Download Attendance" button
  3. System downloads all punches with timezone conversion
  4. Automatically determines check-in/check-out status
  5. View logs in Attendances → Attendance Logs menu

🚀 Installation

⚠️ Requirements:
• Odoo 15.0
• Python 3.7+
• ZKteco device with TCP/IP connectivity
• Network access to biometric devices

Quick Install

  1. Download and place the module in your Odoo addons directory
  2. Restart Odoo server: sudo systemctl restart odoo
  3. Update Apps List from Odoo interface
  4. Search "ZKteco Biometric" and click Install

🆘 Troubleshooting

Common Issues & Solutions

❌ Connection Failed
• Verify device IP address is correct
• Check network connectivity: ping [device_ip]
• Ensure device is powered on and port is correct
• Check firewall settings
❌ Can't Set User
• Device memory may be full - check capacity
• Verify employee name is valid (max 24 characters)
• Ensure card number is a valid integer
• Check for duplicate user IDs
❌ Invalid Card Number
• Card number must contain only digits
• Remove any spaces or special characters
• Can be left empty if not used
